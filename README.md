# 🚀 Nerd_Zone SaaS

Construção de um **SaaS simulado** focado em gerenciamento de fluxos de trabalho e equipes para uma loja de tecnologia chamada **Nerd_Zone** — especializada em **Eletrônicos, Jogos, Consoles e PCs**.

---

## 🧠 Sobre o Projeto

O **Nerd_Zone SaaS** é uma aplicação web moderna que simula uma ferramenta visual para:

* Gerenciamento de tarefas (Kanban)
* Controle de equipe
* Monitoramento de workflows
* Visualização de relatórios e métricas

Tudo isso com uma identidade visual **Nerd/Gamer**, utilizando efeitos modernos como:

* ✨ Glassmorphism
* 💡 Neon Glow
* 🎮 UI imersiva

---

## ⚙️ Stack Tecnológica

* **React + TypeScript**
* **Vite** (build tool)
* **CSS Vanilla (Design System customizado)**
* **react-beautiful-dnd** (drag-and-drop)
* **lucide-react** (ícones)
